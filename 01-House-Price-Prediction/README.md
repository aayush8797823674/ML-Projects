# House Price Prediction using Linear Regression

## Project Overview
This project uses Linear Regression to predict house sale prices based on selected property features.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load and inspect the dataset.
2. Separate rows with known and missing SalePrice values.
3. Encode categorical features using One-Hot Encoding.
4. Split known-price data into training and testing sets.
5. Train a Linear Regression model.
6. Evaluate the model using MAE, RMSE, and R².
7. Visualize actual vs predicted prices and residuals.
8. Predict missing sale prices.

## Model Performance
- MAE: 34,122.85
- RMSE: 54,022.75
- R² Score: 0.6195

## Limitations
The predictions are estimates, not verified market prices. The model uses a limited set of features and could be improved through additional feature engineering and model comparison.
